# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付统计，以及换砂轮后的开机首件确认。

## 砂轮开机首件确认

切片室换砂轮后首批薄片易带烧边或划痕，等观察时才发觉，因此增加开机首件确认：

1. 换砂轮后先建**待确认单**，记录砂轮批号、冷却水流量、磨盘转速和操作人；同一砂轮批号确认解除前不接第二张。
2. 首件查**厚度**（带宽 0.027–0.033mm，目标 0.03mm）、**划痕**、**边缘烧灼**，任一项越界即**转复磨**。
3. 复磨**换人**（复磨操作人不得与上一棒相同），复磨后按厚度、划痕、烧灼重判。
4. 最近**连续两片达标**且无遗留复磨，才解除该砂轮的首件确认；解除后该砂轮批号才能再建单。
5. 样本**钻孔、岩芯箱**或切片**染色方法**更正后，原确认立即作废（记录作废原因），需按新值重新建单、重判。

## 代码结构（业务三分）

- `confirm-rules.js` —— 确认规则：建单唯一性、三项判定、越界转复磨、复磨换人、连续两片解除、更正作废重判（纯规则，不读写文件）。
- `record-store.js` —— 记录保存：JSON 读写、首次建库与历史结构迁移（补 `confirmations`）。
- `page.js` —— 页面操作：HTML 与前端交互（建单、送检、复磨、解除、更正作废、刷新）。
- `server.js` —— HTTP 路由编排，串联以上三个业务文件。
